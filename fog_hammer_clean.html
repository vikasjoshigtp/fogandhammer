Fog & Hammer is a brand and design studio built for companies that operate at national scale — retailers, restaurant groups, hotel brands, financial institutions, and specialty chains that need design work that holds up everywhere they do business.

The fog is where ideas form. The strategy, the concept, the creative thinking that makes a brand distinct. The hammer is how those ideas hit the world — production-engineered, technically precise, and built to perform across every location, every format, and every market.

How We Work

Our Production Workflows

Every project type follows a documented, structured workflow — so you always know exactly where your work stands, who owns each step, and what you'll receive at the end.

Step 01

Design-Ready File

Client provides the approved design-ready file. Brief, specs, and brand references confirmed before work begins.

Step 02

Job Logged

Project inputs logged in our tracking system. Timeline, format specs, and delivery requirements confirmed.

Step 03

Preflight

Production team runs full preflight on incoming files — checking specs, color mode, resolution, bleed, and document structure.

Step 04

Artwork Creation

Production creates the final artwork. All elements placed in keyline, copy fitted, brand rules applied, production specs met.

Step 05

Quality Check

Dedicated QC review — technical accuracy, content fitment, color accuracy, and brand compliance all verified.

Step 06

Final Overlook

Senior team final overlook before any client-facing output. Visual and content sign-off at this stage.

Step 07

Shared with Client

Artwork delivered via secure portal or email. Revision loop restarts from Step 04 if changes are requested.

Step 08

Layout Approval

Client provides written layout and content approval before any file moves to repro or press.

Step 09

Approved File Released

Approved artwork released as final. File enters repro workflow or is archived as a production master.

Step 01

Approved Artwork File

Final layout-approved file received from client. Production master — no further content changes from this point.

Step 02

Job Logged

Repro job logged. Print spec, substrate, print vendor, and delivery format all confirmed at this stage.

Step 03

Repro Print-Ready File

Production builds the final repro file — color separation, trap, overprint, PDF/X output, and vendor-specific settings applied.

Step 04

Quality Check

Full technical QC — Enfocus PitStop Pro preflight, color profile verification, barcode check, and dieline alignment confirmed.

Step 05

Final Overlook

Senior team final visual and production spec overlook before client delivery.

Step 06

Shared with Client

Repro proof sent to client via portal or email for final file approval before release to printer.

Step 07

Final File Approval

Client provides written approval of the repro file. No printer release without explicit sign-off.

Step 08

Released to Printer

Final approved file released directly to the print vendor per agreed specification. Job complete.

Step 01

Approved Released File

Final approved artwork confirmed before 3D work begins. No 3D production on unapproved artwork.

Step 02

Inputs to 3D Team

Approved artwork, structural dieline, substrate specs, and any reference photography shared with the 3D production team.

Step 03

3D File Created

3D team builds the photorealistic model — structural form, material finishes, lighting, and artwork applied to the 3D surface.

Step 04

Quality Check

3D QC review — artwork mapping, reflections, shadow behavior, product proportions, and render resolution all verified.

Step 05

Final Overlook

Senior team final overlook — visual quality, brand accuracy, and marketing suitability confirmed before client delivery.

Step 06

Delivered to Client

Final 3D renders and 360° videos delivered in agreed formats — JPEG, PNG, MP4, or layered PSD as specified.
